# Домашнє завдання 4: Конкурентність та паралелізм

Цей проєкт реалізує паралельний пошук ключових слів у текстових файлах, використовуючи два різні підходи:

1.  **Багатопотоковість** (з використанням модуля `threading` через `ThreadPoolExecutor`).
2.  **Багатопроцесорність** (з використанням модуля `multiprocessing` через `ProcessPoolExecutor`).

Мета — порівняти продуктивність та ефективність обох підходів для задачі, що включає як операції вводу/виводу (I/O), так і обчислення (CPU).

## 🚀 Як запустити

Проєкт не вимагає жодних зовнішніх бібліотек, лише стандартну бібліотеку Python 3.

### Крок 1: Клонування репозиторію

```bash
git clone [https://github.com/mikk1max/goit-cs-hw-04.git](https://github.com/mikk1max/goit-cs-hw-04.git)
cd goit-cs-hw-04
```

### Крок 2: Запуск програми

Просто запустіть головний скрипт main.py з вашого терміналу:

```bash
python3 main.py
```

(Або `python main.py` залежно від вашої системи)

## 🛠️ Що робить скрипт

При запуску `main.py` автоматично виконує наступні дії:

1. Створює директорію `text_files/` у корені проєкту.

2. Генерує 20 тестових файлів (`file_1.txt`... `file_20.txt`) різного розміру, що містять (або не містять) набір ключових слів.

3. Запускає пошук за допомогою `ThreadPoolExecutor` (багатопотоковий).

4. Вимірює та виводить час виконання багатопотокового пошуку.

5. Запускає пошук за допомогою `ProcessPoolExecutor` (багатопроцесорний).

6. Вимірює та виводить час виконання багатопроцесорного пошуку.

7. Порівнює результати обох підходів, щоб переконатися в їх ідентичності.
